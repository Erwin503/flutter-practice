# Sun Stickers

Практика Flutter по учебнику SunStickers.

## Шаг 1

Создан базовый Flutter-проект с поддержкой Android, iOS и Web.

## Шаг 2

Добавлены изображения стикеров, класс `AppAsset` с путями к ресурсам и шрифт `AppIcon` с пользовательскими иконками.

## Шаг 3

Добавлена палитра `AppColor` для светлого и тёмного оформления приложения.

## Шаг 4

Добавлены и подключены светлая и тёмная темы `AppTheme`.

## Шаг 5

Добавлены текстовые стили `AppTextStyle` и подключены к темам приложения.
